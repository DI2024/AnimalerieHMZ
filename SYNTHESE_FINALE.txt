🐛 DÉPANNAGE RAPIDE
═══════════════════════════════════════════════════════════════════════════

PROBLÈME: Les images ne s'affichent pas
SOLUTION:
  1. Vérifier que les images existent
  2. php artisan storage:link
  3. Vérifier les permissions

PROBLÈME: Erreur "Foreign key constraint"
SOLUTION:
  Le script désactive automatiquement les contraintes
  Si l'erreur persiste:
    SET FOREIGN_KEY_CHECKS = 0;
    -- Votre script
    SET FOREIGN_KEY_CHECKS = 1;

PROBLÈME: Nombre de produits incorrect
SOLUTION:
  1. Restaurer la sauvegarde:
     mysql -u root -p animaleriehmz < backup.sql
  2. Ré-exécuter le script

PROBLÈME: Erreur MySQL "Access denied"
SOLUTION:
  1. Vérifier que MySQL est démarré
  2. Vérifier les identifiants (root/password)
  3. Vérifier que la base "animaleriehmz" existe
